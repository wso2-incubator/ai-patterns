This folder contains supporting material for following
* the paper "A Methodology for Investigating AI Patterns Prevalence in Software Repositories," published in PATTERNS 2026
* "A Methodology for Finding and Estimating Software Design Patterns Prevalence in
Software Repositories", an extended version of the paper under review in IARIA Journal.


List of supporting material

* prompts - includes the prompts 

* ai - includes content for AI pattern detection
**  ai/ai_sources_for_mining_pattern_candidates.csv - sources used to find pattern candidates
** ai/ai_repositories_mined_for_communities.csv -- repositories mined 

* microservices - includes content for microservices pattern detection
** microservices/ms_sources_for_mining_pattern_candidates.csv - sources used to find pattern candidiates
** microservices/ms_repositories_mined_for_communities.csv.csv - repossiteris mined 

* sources - include the sources. The difference between the patterns 2026 paper and journal paper code is in step 3, and you can find details in the documentation [source_code/README.md](source_code/README.md).
