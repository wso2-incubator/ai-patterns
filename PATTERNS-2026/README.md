
This folder contains supporting material for following
* the paper "A Methodology for Investigating AI Patterns Prevalence in Software Repositories," published in PATTERNS 2026
* "A Methodology for Finding and Estimating Software Design Patterns Prevalence in
Software Repositories", an extended version of the paper under review in IARIA Journal.


List of supporting material

* sources_for_mining_pattern_candidates.csv - sources used for mining pattern candidates 
* repositories_mined_for_communities.csv - repositories used for finding code communities 
* prompt_extracting_pattern_candidates.txt - prompts used for extracting patterns in step 1
* prompt_suumarizing_clusters.txt - prompts used for summarizing cluster patterns in step 1
* prompt_llm_as_judge_patterns.txt - prompts used for verifying patterns in step 3
* 14_pattern_classes_descrptions.md
* pattern_classes_to_refined_pattern_candidates.json - mapping from refined pattern classes to 14 patterns after manual classification in step 2 
* verified_communities_with_labels.csv  - verified community labels after 4 iterations of active learning in step 3 - path refers to the code in extracted-communities-step2.zip
* Extracted-communities-step2.zip - all extracted communities ( each community is in a single file) 
* source_code - source code for all steps
